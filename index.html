About

Who I am.

I'm a systems engineer working at the boundary between software and hardware. I build APIs that interact directly with the operating system and distribute automation software across machines to run tests on physical hardware. My current stack is Go (Golang) and Python, with a production background in HTTP/3 and PostgreSQL.

I'm self-studying RTOS internals and embedded systems with the goal of understanding how real-time constraints work at the hardware level. I care about systems that have to work in the real world, under real constraints.
